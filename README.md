### 🚀 Projetos em Destaque

- **[Poker Vision Engine](https://github.com/TheoEnderson/poker-vision-engine)**  
  Assistente autônomo em tempo real para Texas Hold'em. Utiliza OpenCV, Tesseract OCR, Máquina de Estados Finitos (FSM) e simulação de Monte Carlo para cálculo de EV e decisão probabilística.

- **[Simulador RISC-V RV32I/M (Poxim-V)](https://github.com/TheoEnderson/ARQUITETURA)**  
  Emulador de processador RISC-V desenvolvido em C99 puro, com suporte a instruções RV32I/M, interrupções (M-Mode), periféricos MMIO e emulação de memória Cache L1 set-associative com métricas de hit/miss rate.

- **[Estruturas de Dados em C](https://github.com/TheoEnderson/estrutura-de-dados)**  
  Implementações modulares em C abordando algoritmos e estruturas essenciais: árvores binárias, tabelas hash, filas, pilhas, grafos e análise assintótica de complexidade.
